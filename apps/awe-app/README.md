# AWEp2P App

Native Tauri shell for the AWEp2P UI.

- Windows: native installer + bundled AWE node.
- Linux: AppImage/deb/rpm + bundled AWE node.
- macOS: DMG/app + bundled AWE node.
- Android: APK/AAB UI shell. The Android build does not launch the desktop node binary; use a reachable AWE API/node endpoint when mobile networking is enabled.

The shared UI lives in `apps/awe-desktop/ui`.
